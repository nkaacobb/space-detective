# Space Detective

A Rust desktop app that shows where your disk space went. Pick a folder or drive and every file
becomes a box sized by how much space it takes. Folders become boxes holding their contents.

```
cargo run --release
cargo run --release -- "D:\Some\Folder"   # scan a folder straight away
```

The Rust version is pinned in `rust-toolchain.toml`, and rustup installs it automatically.

## Using it

- **Browse…**, type a path and press Enter, or click a drive button to start a scan.
- **Hover** a box to see its name, path and size.
- **Click** a box to investigate it: the detective sends his magnifying glass over and comments on
  it, and the *Selected* card shows its details.
- **Double-click** a box to go inside its folder. Use **Up**, the breadcrumb tabs, Backspace or the
  mouse back button to come back out.
- **Right-click** a box to go inside, show it in Explorer or Finder, or copy its path.
- **M** (or the magnifying-glass button by the detective) lends you his glass: it follows the mouse
  over the map and really magnifies what's underneath. The speaker button mutes him.
- Colours show file types. The biggest types get their own colours, listed under *File types*.

Symlinks, junctions and mount points aren't followed. Folders and big files that show up at more
than one path (hard links, or antivirus sandboxes that mirror the disk) are counted once, at their
shortest path. Sizes are file sizes, not the space allocated on disk.

## The detective

He's a paper puppet built from `Warm Storybook Detective Character Study.png`. Everything he's made
of is generated by scripts in `art/` (Python with Pillow, numpy, scipy and requests) using a local
ComfyUI; the ComfyUI workflows are in `workflows/`.

| Script | Makes |
| --- | --- |
| `art/cut_parts.py`, `art/cutout_parts.py`, `art/finish_parts.py` | His puppet parts, cut from the character study, upscaled and masked |
| `art/make_eyes.py` | The head without pupils (the app draws pupils that follow the mouse) and the nose layer |
| `art/preview_rig.py` | A preview of the rig in `assets/detective/rig.json` |
| `art/make_props.py` | The desk props, fingerprint, compass and paperclip (Z-Image Turbo) |
| `art/make_textures.py` | The navy desk, parchment and paper-grain textures |
| `art/make_voice.py` | His voice lines from `assets/voice/lines.json`: Qwen3-TTS cloned from `art/voice_reference.wav` (the approved voice), three takes per line with fixed seeds 1101–1103, keeping the take that Whisper confirms and that sounds closest to the approved voice. The kept seed of each line is locked in `art/voice_seeds.json` |
| `art/voice_match.py`, `art/speaker_match.py` | How closely clips match the approved voice (pitch and timbre; Qwen3-TTS's own speaker encoder) |
| `art/make_fonts.py` | Switches Alegreya Sans to lining digits by default (fonts are in `assets/fonts`, SIL Open Font License) |

To add lines, put them in `assets/voice/lines.json` and run `python art/make_voice.py`: it records only
lines that aren't locked yet. Approved lines stay as they are; to re-record one, pass its id with `--redo`,
or `--use <seed>` to go back to a take that's already on disk. New clips are picked up by the next build.

`SPACE_DETECTIVE_DEMO=<folder>` runs a scripted walkthrough that saves screenshots of each state to
that folder and then quits, for checking the look without clicking around.

## Making installers

The version comes from `version` in `Cargo.toml`. Bump it before each release.

**Windows** (on a Windows PC with [Inno Setup](https://jrsoftware.org/isdl.php) installed):

```
powershell -ExecutionPolicy Bypass -File packaging\windows\build-installer.ps1
```

This makes `dist\SpaceDetective-Setup-<version>.exe`. It installs for the current user without
needing admin rights, adds a Start menu entry and an optional desktop shortcut, and has an
uninstaller. The C runtime is linked in, so it needs nothing else on the PC.

**macOS** (on a Mac with Rust and the Xcode command line tools):

```
bash packaging/macos/build-dmg.sh
```

This makes `dist/SpaceDetective-<version>.dmg` with a universal app for Apple Silicon and Intel Macs.

**Both at once, on GitHub:** `.github/workflows/release.yml` builds both on GitHub's Windows and
Mac machines. Run it from the repository's Actions tab, or push a tag such as `v0.1.0` to get a
draft release with both files attached.

### Warnings people will see

Neither download is code-signed yet, so:

- **Windows** SmartScreen says "Windows protected your PC". People click *More info* → *Run anyway*.
  Signing the installer (for example with Azure Trusted Signing, or a code-signing certificate)
  removes this.
- **macOS** says the app can't be checked for malware. People open *System Settings › Privacy &
  Security* and click *Open Anyway*. An Apple Developer account ($99/year) lets `build-dmg.sh`
  sign and notarize the app (see the top of that script), which removes this.

The app icon is drawn by `packaging/make_icons.py` (needs Pillow). It writes everything in `assets/`.
